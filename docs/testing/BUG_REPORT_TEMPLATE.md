# Formulir Laporan Kendala Sistem (Bug Report Template)

Gunakan templat ini untuk melaporkan anomali, kesalahan kalkulasi, atau kegagalan aplikasi saat pengujian SABIT.

---

## 1. Ringkasan Masalah
- **Judul Masalah**: `[Ringkasan singkat, misal: Slider Gain tidak merespons pada kamera ASCOM]`
- **Tingkat Keparahan**: `[ Kritis (Crash) / Mayor (Fungsi tidak berjalan) / Minor (Kosmetik/UI) ]`
- **Kode Partisipan**: `[Contoh: OBS-01]`
- **Tanggal Kejadian**: `[YYYY-MM-DD]`

---

## 2. Lingkungan Pengujian
- **Versi SABIT**: `1.0.0 (Release Build x64)`
- **Sistem Operasi**: `[Windows 10 22H2 / Windows 11]`
- **Spesifikasi Laptop/PC**: `[Model Prosesor, Kapasitas RAM]`
- **Perangkat Kamera**: `[Nama Model Kamera / Capture Card / Simulator]`
- **Driver Kamera**: `[Versi Driver Vendor / DirectShow / ASCOM Platform]`

---

## 3. Langkah Mereproduksi Masalah (Steps to Reproduce)
1. Buka aplikasi SABIT.
2. ...
3. ...
4. Amati anomali yang terjadi.

---

## 4. Perilaku yang Diharapkan vs Perilaku Aktual
- **Ekspektasi**: `[Apa yang seharusnya terjadi secara normal]`
- **Aktual**: `[Apa yang sebenarnya terjadi di layar aplikasi]`

---

## 5. Berkas Log & Bukti Pendukung
- Lampirkan berkas log yang dihasilkan aplikasi pada:
  `%LOCALAPPDATA%\Programs\Sabit\app.log` atau direktori sesi terkait.
- Tangkapan layar (screenshot) pesan error jika tersedia.
